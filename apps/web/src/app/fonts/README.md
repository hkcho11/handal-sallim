# App font

Pretendard Variable 1.3.9 is self-hosted through `next/font/local` so Korean text and numerals render consistently without a browser request to an external font service.

- Source: https://github.com/orioncactus/pretendard/tree/v1.3.9
- Original file: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`
- License: SIL Open Font License 1.1, included in `OFL.txt`.
- The original font is unmodified. The 2 MB variable file is cached after its first load; `font-display: swap` keeps content readable during loading.
