# 홈 대시보드

2026-10-14 사용자 요청 기준. 이전 홈 구성보다 이 문서의 최신 구성을 우선한다.

- [UI Bowl 모으미](https://uibowl.io/name/%EB%AA%A8%EC%9C%BC%EB%AF%B8)의 데이터가 있는 메인 화면과 [WWIT 네이버페이](https://wwit.design/2025/02/15/npay/)의 소비 화면을 직접 확인했다. 짧은 라벨과 금액 중심 요약, 묶음별 정보 위계, 선택해서 내역을 확인하는 구성을 참고한다.
- 홈은 월, 지출 요약, 카테고리 통계, 실제 등록 고정비, 결제수단 요약 순서로 보여준다.
- 홈의 지출 요약·카테고리 통계·실제 지출 내역은 고정비와 공동 지출만 포함한다. 개인 지출은 본인 것이라도 홈의 금액·비중·목록에서 제외한다. 개인 거래의 서버 조회 권한은 별도 개인 지출 기능에서 적용한다.
- 지출 요약은 모바일에서도 `실제 지출 | 남은 지출 | 월 예상 지출` 한 줄이다. 실제·남은 지출을 누르면 바로 아래 목록을 펼치고, 같은 항목을 다시 누르면 닫는다.
- 다가오는 결제·지연 목록과 별도 결제 현황 카드는 중복이므로 홈에 두지 않는다. 지연 정보는 남은 지출 목록에 표시한다.
- 설명 문단, 계산 안내, 공동·개인 수입·지출 반복 요약은 홈에서 제거한다. 이름·금액·상태처럼 판독에 필요한 값만 남긴다.
- 홈은 `/api/dashboard`에서 현재 서울 날짜의 월간 공동 거래와 고정비 청구를 조회한다. 프론트의 예시 데이터와 예시 배지는 제거하며 목데이터는 테스트 fixture에만 둔다.
- 실제 지출은 DB의 활성 공동 지출 거래로 집계한다. 완료 고정비는 연결된 실제 거래를 한 번만 포함하고, 월 예상은 실제 지출과 미완료 고정비 예정액을 합산한다. 결제수단별 예상액도 확정 공동 지출과 남은 고정비 예정액의 합계다.
