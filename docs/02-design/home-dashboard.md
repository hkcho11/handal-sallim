# 고정비 홈 통계

기준: SERVICE_PLAN.md 1.3 및 2026-10-14 사용자 답변. 기존 홈의 지출 요약·일반 공동 거래 통계·등록 고정비 미리보기를 교체한다. 시각 기준은 기존 블루 토큰과 한글 폰트를 유지한다.

- 순서: 조회 월 → 선택 월 지출 요약 → 대분류별 지출 통계 → 선택한 중분류별 월별 변화 → 결제수단별 지출.
- 선택 월 요약은 완료 건의 실제 지출, 전체 청구 예상액, 미결제 건의 남은 예정액, 건수 기준 결제 완료율과 지연 건수를 표시한다. 실제액을 예상액에서 빼서 미결제액을 계산하지 않는다. 청구가 없는 달은 빈 화면 안내와 고정비 등록 링크를 제공한다.
- 집계 월은 **예정 결제월**이다. 10월 청구를 11월에 결제해도 10월에 실제액을 반영한다.
- 대분류 차트는 예상/실제를 전환한다. 처음에는 그 달의 청구 예상액을 표시한다. 대분류 행을 펼치면 해당 고정비와 중분류, 금액·상태를 확인하고 지출 상세로 이동할 수 있다.
- 분류 ID로 합산한다. 메모나 이름으로 그룹을 만들지 않으며 같은 중분류에 속한 여러 내역을 합산한다. 분류가 없는 기존 청구는 미지정으로 따로 표시한다.
- 중분류의 월별 비교는 선택 월까지 최근 6개월의 실제 결제액이다. 미결제 건은 0원이고 미결제 건수와 예정액을 함께 보여준다. 청구 기록 자체가 없는 달은 `기록 없음`이다. 반복 설정을 과거 달에 임의로 복제하지 않는다.
- 증감은 `+10,000원 (+22.2%)` 형식이다. 전월 기록이 없으면 비교 기록 없음, 전월 기준액이 0원이면 증감액만 계산하고 증감률은 `—`이다.
- 월별 차트는 원 단위이며 정확한 월 금액과 증감은 펼침 표에서도 확인할 수 있다. 대분류·중분류 선택창에 접근성 이름을 제공한다.
- 결제수단은 미완료 청구의 **예정 결제수단/예정액**과 완료 청구의 **실제 결제수단/실제액**을 다른 열에 표시한다. 미지정도 별도 행이다. 결제수단 표시명이 같아도 ID가 다르면 합치지 않는다.
- 결제 일정·미결제 목록은 세 통계 아래의 접힌 영역에서 접근한다. 일정 미정 고정비는 별도 안내와 상세 링크로 확인하며 월 통계에 넣지 않는다.
- `/api/dashboard/fixed-costs?month=YYYY-MM`은 활성 공간 멤버에게만 제공한다. 예정 청구를 한 번만 반환하고 생성 거래·일반 거래·개인 거래·수입·저축을 합산하지 않는다. 취소 청구도 제외한다. 기존 `/api/dashboard`는 호환성을 위해 유지한다.
- 초기 월은 서버의 서울 날짜 기준 월이다. 이전/다음/월 입력과 이번 달 이동을 지원한다. 월을 바꾸면 이전 응답이 섞이지 않도록 새 조회 상태로 전환한다.
- `통계 새로고침`은 선택한 월을 유지하고 API를 다시 조회한다. 실패 시 재시도를 제공하며 이전 금액을 최신 통계로 표시하지 않는다.
- 테스트 데이터는 사용자가 로컬 DB에 준비한다. 홈은 `scheduled_charges`의 예정 결제월(`due_date`)과 실제 결제 정보로 집계한다. `recurring_expenses` 설정만 있거나 `transactions`에만 넣은 데이터는 월별 고정비 통계에 합산하지 않는다. 일정이 없는 활성 고정비는 별도 안내로 표시한다. 완료 데이터는 기존 완료 처리 API를 이용하면 청구와 실제 거래의 일관성을 유지할 수 있다.
