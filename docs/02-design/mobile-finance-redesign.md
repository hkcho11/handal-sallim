# 모바일 가계부 화면 개편

2026-10-14. 기존 녹색 화면을 전면 재검토하라는 사용자 요청에 따른 최신 시각 기준이다. 기존 가이드의 녹색 팔레트보다 이 문서와 `globals.css` 토큰을 우선한다.

과거 화면 기록은 최신 앱 기능을 단정하는 자료로 쓰지 않는다. 브랜드·이미지·화면을 복제하지 않고 정보 위계와 탐색 방식을 참고했다.

## 구성과 동작

- 주요 색상은 블루 `#315beb`, 본문은 `#202632`, 배경은 `#f5f6fa`. 선택 상태와 버튼에 주요 색상을 쓰고 오류·지연은 붉은 색과 텍스트로 구분한다.
- 한글·숫자는 로컬 Pretendard Variable로 통일한다. 입력은 16px 이상, 주요 조작은 44px 이상, 입력 필드와 저장 버튼은 52px을 기본으로 한다.
- 앱 전체 폭은 최대 720px. 홈·고정비·개인 지출·등록·상세가 같은 폭과 색상 토큰을 사용한다. 하단 메뉴도 앱 폭에 맞추고 안전 영역을 확보한다.
- 홈은 월 → 실제·남은·예상 지출 → 카테고리 통계 → 결제수단 → 고정비 미리보기 순서다. 개인 지출은 포함하지 않는다.
- 실제·남은 지출은 `내역 보기`와 화살표를 가진 버튼이다. 바로 아래 내역을 펼치며 배경·테두리·화살표로 선택 상태를 표시한다. 닫기/Escape는 원래 버튼으로 초점을 돌려준다.
- 펼친 목록에서 지출명·결제수단을 검색한다. 실제 지출은 카테고리도 검색할 수 있다. 빈 검색 결과를 따로 안내하며 요약 종류를 바꾸면 검색을 초기화한다.
- 카테고리는 도넛 차트와 비중순 목록으로 표시한다. 각 행을 펼치면 해당 거래가 나온다. 차트에는 텍스트 대체 설명을 붙인다.
- 결제수단은 실제/예상 선택으로 금액을 확인한다. 고정비는 최대 3개를 미리 보고 관리 화면에서 전체를 확인한다.
- 진행 막대는 실제 지출/월 예상 지출 비율이다. 예산 소진율이나 고정비 완료 건수 비율이 아니다.
- 홈의 월은 서버가 반환한 현재 월이다. 아직 지원하지 않는 과거 월 선택이나 공동 거래 등록 버튼을 실제 기능처럼 만들지 않는다. 홈의 추가 버튼은 현재 연결된 기능에 맞춰 `고정비 추가`로 표시한다.

## 검증 범위

실제 로컬 DB의 홈·고정비·개인 지출을 모바일 폭에서 확인한다. 자동 검증은 홈 검색·내역 펼침·카테고리·결제수단 전환·하단 메뉴, 360/1280px, 키보드 초점, 200% 글자 확대, 빈 데이터·재시도를 포함한다. iPhone 실기기 및 느린 모바일 네트워크 검증은 별도다.
