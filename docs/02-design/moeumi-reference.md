# 모으미 UI/UX 참고와 가계부 구성

기준일: 2026-10-13. 사용자가 지정한 [UI Bowl 모으미 페이지](https://uibowl.io/name/%EB%AA%A8%EC%9C%BC%EB%AF%B8)의 `메인 - 데이터 없음`, `메인 - 데이터 있음`, `내역 - 가계부 탭` 화면을 확인했다. 화면 사례로 관찰한 내용과 한달살림에서 선택한 구성을 구분해 기록한다. 실제 앱의 동작·정확성·권한 정책을 검증한 결과는 아니다.

## 관찰한 화면 패턴

- 밝은 배경 위에 둥근 카드로 요약과 기능을 묶고, 큰 금액과 작은 보조 문구로 정보 위계를 만든다.
- 홈에서 월간 가계부 요약, 지난달 요약과 자동이체 안내를 카드로 보여준다. 데이터가 없는 카드에는 등록 행동이 있다.
- 가계부는 월 선택, 월간 요약, 달력과 날짜별 내역을 연결한다.
- 날짜별 내역에는 검색과 전체·수입·지출 선택이 있고 항목별 이름·카테고리·날짜·금액을 구분한다.

## 한달살림에 적용할 구성

| 위치            | 구성                                         | 적용 정책                                                                                 |
| --------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 홈              | 고정비 일정과 상태, 월간 생활비 요약 카드    | 고정비 80%·가계부 20%의 제품 비중을 유지한다. 임박·지연을 먼저 보여준다.                  |
| 고정비 탭       | 조회 목록, 우측 상단 추가 버튼, 상세         | 목록에서 입력하지 않는다. 상세의 정보 수정 화면에서 모든 항목을 편집한다.                 |
| 가계부 상단     | 월 이동, 확정 수입·확정 지출·차액            | 원 단위 정수와 현재 공개 범위를 적용한다. 차액을 실제 자산 잔액으로 표현하지 않는다.      |
| 가계부 본문     | 날짜 선택 달력과 일별 내역                   | 미완료 예정 청구와 실제 지출을 구분한다. 완료로 생성된 거래만 확정 지출에 한 번 포함한다. |
| 내역 탐색       | 전체·수입·지출, 검색, 기간·카테고리·결제수단 | 공동과 본인 개인 내역의 조회 범위를 유지한다.                                             |
| 거래 항목       | 이름·금액·카테고리·결제수단과 고정비 출처    | 선택하면 상세로 이동하고 수정은 상세에서 시작한다.                                        |
| 기본 분석       | 카테고리별 확정 지출, 월간 수입·지출 비교    | 동일한 공개 범위와 계산 기준을 사용하고 텍스트 값을 함께 제공한다.                        |
| 첫 사용·빈 화면 | 짧은 설명과 해당 기능의 추가 버튼            | 실제 데이터 없는 곳에 등록을 안내한다. 예시 데이터가 실제 합계에 섞이지 않게 한다.        |

가계부와 분석 구성은 기획에 반영한 내용이다. 이번 구현 범위는 고정비 목록·추가·상세와 전체 정보 수정이다. 미구현 가계부 화면은 기능을 만들 때 이 기준을 적용한다.

## 후속 검토

예산·남은 예산은 별도 정책 결정 후 추가할 후보다. 예산 기간, 이월, 초과 표현과 공동·개인 구분을 확정해야 한다. 투자·주식·예적금·시장 정보·은행 잔액은 기존 MVP 비목표를 유지한다.

시각 구성은 모으미의 카드·정보 위계를 참고하되 한달살림의 공통 색·여백·버튼과 접근성 기준을 사용한다. [공통 UI/UX 가이드](ui-ux-guide.md)를 모든 신규·개선 화면에 적용한다.
