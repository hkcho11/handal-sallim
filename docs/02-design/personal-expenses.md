# 개인 지출 탭

2026-10-14 사용자 요청에 따라 첫 단계는 탭과 화면 구성으로 제한한다.

- 하단 메뉴는 홈, 고정비, 개인 지출 순서로 표시한다.
- 개인 지출 경로는 `/personal-expenses`이며 해당 화면에서 탭을 활성화한다.
- 서울 시간 기준 이번 달로 시작한다. 이전 달, 다음 달, 이번 달 이동을 제공한다.
- 월간 개인 지출 합계와 지출 내역 영역을 구성한다.
- 데이터 연결 전에는 `화면 미리보기`와 준비 중 안내를 표시한다. 합계를 0원이나 예시 금액으로 표시하지 않는다.
- `지출 추가`는 등록 기능 연결 전까지 비활성 상태로 표시한다.

거래 등록, 조회, 수정, 실제 합계 집계와 API 연결은 후속 구현 범위다. 실제 개인 거래를 연결할 때는 서버에서 작성자 권한을 검증하고 공동 내역과 합계에서 제외한다.
