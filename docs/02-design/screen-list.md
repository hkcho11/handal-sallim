# 한달살림 MVP 화면 목록

> 상태: Draft — 사용자 승인 전 구현 기준으로 사용하지 않음
>
> 기준: `SERVICE_PLAN.md` 0.7
>
> 범위: 로그인·인증 화면을 제외한 반응형 웹 MVP

## 1. 화면 구성 원칙

- 첫 화면에서 이번 달 미완료·지연 고정비를 가장 먼저 확인하게 한다.
- 모바일에서는 핵심 행동을 한 열로 완료하고 데스크톱에서는 같은 정보를 넓게 재배치한다.
- 생성·수정·완료·삭제는 URL로 복원 가능한 페이지를 기본으로 하며 단순 확인만 대화상자를 사용한다.
- 함께 관리의 개인 거래 존재 여부를 상대 사용자 화면에 노출하지 않는다.
- 빈 상태, 로딩, 오류와 결제수단 미지정 상태를 정상 화면의 일부로 설계한다.
- 인증 전후 진입과 계정 복구는 별도 인증 기획에서 추가한다.

## 2. 전역 내비게이션

| 영역 | 모바일 | 데스크톱 |
|---|---|---|
| 주 내비게이션 | 하단: 홈, 고정비, 거래, 더보기 | 좌측: 홈, 고정비, 거래, 결제수단, 공간·설정 |
| 월 이동 | 화면 제목 아래 이전·현재·다음 | 콘텐츠 헤더의 월 선택기 |
| 생성 행동 | 주요 화면의 `내역 추가` 버튼 | 주요 화면의 `내역 추가` 버튼 |
| 사용자/공간 | 더보기 내부 | 좌측 내비게이션 하단 |

전역 중앙 `+` 아이콘만 단독으로 사용하지 않는다. 홈과 주요 목록의 `내역 추가` 버튼은 같은 통합 입력 화면으로 이동하고, 사용자가 고정 또는 일반을 선택하면 해당 필드를 보여준다.

## 3. 화면 목록

### 3.1 시작과 공간

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| SPACE-EMPTY | 공간 없음 | 첫 공간 추가 안내 | 공간 없음, 재시도 오류 |
| SPACE-MODE | 관리 방식 선택 | 혼자/함께 관리 선택 | 기본값 없음 |
| SPACE-INVITE | 함께 관리 초대 | 24시간 초대 링크·코드 확인 | 발급, 복사, 만료, 취소, 재발급 |
| SPACE-OVERVIEW | 공간 관리 | 멤버와 초대 상태 확인 | SOLO, SHARED_PENDING, SHARED |
| SPACE-CONVERT | 함께 관리 전환 검토 | 기존 거래의 공개 범위 검토 | 미검토 거래, 검토 완료 |

### 3.2 홈

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| HOME-MONTH | 월간 홈 | 이번 달 고정비와 합계 파악 | 정상, 빈 달, 로딩, 오류 |
| HOME-CHARGE | 예정 청구 상세 | 한 회차의 예정·실제 정보 확인 | 예정, 지연, 완료, 결제수단 미지정 |

### 3.3 통합 내역 등록

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| ENTRY-CREATE | 내역 추가 | 고정/일반 선택 후 같은 화면에서 유형별 입력 | 유형 미선택, 고정비, 일반 거래, 검증 오류, 저장 오류 |

신규 등록만 통합한다. 저장된 고정비와 일반 거래는 서로 다른 도메인 데이터이므로 수정 화면에서 유형을 바꾸지 않는다.

### 3.4 반복 고정비

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| FIXED-LIST | 고정비 목록 | 활성·중지 고정비 조회 | 정상, 검색 결과 없음, 전체 빈 상태 |
| FIXED-DETAIL | 고정비 상세 | 현재 설정과 예정 회차 확인 | 활성, 중지, 종료 |
| FIXED-EDIT-ONE | 이번 회차 변경 | 선택한 청구 스냅샷만 변경 | 완료 청구 편집 차단 |
| FIXED-EDIT-FUTURE | 다음 회차부터 변경 | 새 설정 revision 생성 | 적용 시작 회차 확인 |
| FIXED-DELETE | 고정비 삭제 확인 | 선택 회차와 이후 미완료 청구 삭제 | 영향 회차 표시, 처리 중, 오류 |

### 3.5 결제 완료

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| CHARGE-COMPLETE | 결제 완료 확인 | 실제 금액·날짜·결제수단 확정 | 기본값 채움, 결제수단 미지정, 중복 요청 |
| CHARGE-EDIT | 완료 내용 수정 | 연결 거래와 함께 수정 | 정상, 충돌, 권한 오류 |
| CHARGE-UNDO | 완료 취소 확인 | 청구 복귀와 거래 무효화 | 영향 설명, 처리 중, 오류 |

### 3.6 결제수단

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| PAYMENT-LIST | 결제수단 목록 | 카드·계좌·현금 조회 | 정상, 빈 상태, 보관 항목 숨김 |
| PAYMENT-DETAIL | 결제수단 상세 | 연결 고정비와 월 합계 확인 | 연결 있음, 연결 없음 |
| PAYMENT-FORM | 결제수단 등록·수정 | 안전한 표시 정보 입력 | 신규, 수정, 검증 오류 |
| PAYMENT-ARCHIVE | 결제수단 보관 확인 | 대체 없이 보관하고 미래 회차 미지정 | 영향 고정비 표시, 처리 중 |

### 3.7 일반 거래

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| TX-LIST | 거래 목록 | 월별 수입·지출 확인 | 공동, 내 개인, 빈 상태 |
| TX-EDIT | 거래 수정 | 저장된 직접 거래 수정 | SOLO, SHARED, 검증 오류 |
| TX-DETAIL | 거래 상세 | 출처와 입력 정보 확인 | 직접 입력, 고정비 자동 생성, 무효 |

### 3.8 설정

| ID | 화면 | 목적 | 핵심 상태 |
|---|---|---|---|
| CATEGORY-LIST | 카테고리 관리 | 공간별 카테고리 관리 | 활성, 보관, 사용 중 |
| SETTINGS | 기본 설정 | 공간·표시·데이터 관련 진입 | 인증 설정 제외 |

## 4. MVP 화면에서 제외

- 랜딩 페이지와 마케팅 페이지
- 로그인, 회원가입, 계정 복구와 소셜 로그인
- 은행·카드 연결과 수집 거래 매칭
- Web Push·이메일 알림 설정
- 예산, 자산, 카드 혜택과 통계 전용 화면
- PWA 설치 유도 전용 화면
- 관리자 콘솔

## 5. 공통 상태 체크리스트

모든 데이터 화면은 해당하는 상태를 설계·테스트한다.

- 최초 로딩 skeleton
- 결과가 없는 정상 빈 상태
- 네트워크 오류와 다시 시도
- 저장 중 중복 제출 방지
- 권한 없음과 존재하지 않음의 안전한 처리
- 긴 비용명·결제수단명·메모
- 큰 금액과 큰 글자
- 키보드 포커스와 오류 요약
- 모바일 360px 폭과 데스크톱 1280px 폭
