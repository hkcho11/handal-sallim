# 한달살림 공통 UI/UX 가이드

상태: 사용자 요청으로 확정한 공통 방향. 제품 요구사항의 기준은 `SERVICE_PLAN.md`이며 이 문서는 화면 구성 기준을 구체화한다.

## 참고 자료와 적용 범위

- [WWIT](https://wwit.design/): 금융·생활 서비스의 홈, 목록, 선택, 입력, 로딩, 성공, 설정과 팝업 사례를 탐색하는 참고 자료.
- [UI Bowl](https://uibowl.io/): UI 패턴, 서비스 유형과 색을 기준으로 사례를 비교하는 참고 자료.
- [모으미 구체 사례](https://uibowl.io/name/%EB%AA%A8%EC%9C%BC%EB%AF%B8): 월간 요약 카드, 달력·내역 연결, 수입·지출 필터와 빈 상태 안내를 우선 참고한다. 적용할 가계부 구성은 `SERVICE_PLAN.md` 11.2와 [참고 정리](moeumi-reference.md)를 따른다.

두 자료는 사례 모음이다. 아래의 색상·치수·동작은 한달살림이 선택한 기준이며 해당 사이트의 의무 규칙이나 최신 유행에 대한 단정이 아니다. 화면을 만들거나 개선할 때 목적에 맞는 사례를 비교하고 정보 구조와 동작을 적용한다. 이미지·브랜드·화면을 그대로 복제하지 않는다. 모든 제품 화면에 적용하며 기능이 생길 때 같은 기준으로 구성한다.

## 정보와 화면 흐름

| 화면           | 구성과 주요 행동                                                                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 월간 홈        | 이번 달 타임라인, 임박·지연 항목, 월간 요약 순으로 구성한다. 금액·날짜·상태를 먼저 보여준다.                                                                                       |
| 고정비 목록    | 등록한 고정비를 카드 목록으로 표시한다. 제목과 우측 상단 `+` 버튼, 목록과 건수를 보여준다. 항목 전체를 상세로 이동하는 링크로 제공한다.                                            |
| 고정비 추가    | 기존 목록을 제거하고 입력에 집중하는 한 열 폼을 제공한다. 저장 후 상세로 이동한다.                                                                                                 |
| 고정비 상세    | 이름·금액·상태를 상단에, 반복주기·반복 결제일·결제자·결제수단·첫 결제일을 읽기 전용 정보로 표시한다. 모든 정보는 별도 수정 화면에서 편집한다.                                      |
| 수정·정보 수정 | 상세에서 진입한다. 변경 가능한 항목과 저장·취소를 명확하게 보여준다. 정보 수정은 기존 값도 변경할 수 있으며 완료 기록은 보존한다. 일반 수정의 회차 적용 범위는 제품 정책을 따른다. |
| 결제 완료 확인 | 실제 금액·날짜·결제수단 확인 후 완료하도록 구성한다. 저장 중 중복 제출을 방지한다.                                                                                                 |
| 결제수단·거래  | 목록 → 상세 → 등록·수정 흐름과 같은 필드·버튼·상태 표현을 사용한다.                                                                                                                |
| 가계부         | 월 선택 → 확정 수입·지출·차액 요약 → 달력 → 선택 날짜의 내역 순으로 구성한다. 전체·수입·지출, 검색과 필터를 제공하며 고정비 출처를 표시한다.                                       |
| 가계부 분석    | 카테고리별 확정 지출과 월간 수입·지출 비교를 보여준다. 개인·공동 범위와 숫자 텍스트를 함께 표시한다.                                                                               |
| 공간·초대·설정 | 현재 상태와 다음 행동을 먼저 보여준다. 공개 범위 변경과 초대 수락은 영향을 확인할 수 있도록 구성한다.                                                                              |

목록의 미정 값은 `-`로 표시하며 폼을 직접 펼치지 않는다. 추가·수정 페이지는 URL로 다시 접근 가능한 화면을 기본으로 한다. 짧은 수정 팝업을 도입할 때는 대화상자 이름, 초점 제한, Escape로 닫기, 닫은 뒤 원래 버튼으로 초점 복원을 함께 제공한다. 미저장 값이 사라지는 전환은 알린다.

## 공통 시각 구성

고정비 삭제는 목록의 왼쪽 스와이프로 나타나는 빨간 휴지통 버튼과 상세 내역 카드 내부 우측 상단의 회색 휴지통 아이콘으로 제공한다. 스와이프는 버튼을 드러내는 동작이며 즉시 삭제하지 않는다. 세로 스크롤과 탭 상세 이동을 유지하고 한 번에 하나의 항목만 펼친다. 키보드로 목록 항목에서 왼쪽 방향키를 눌러 버튼을 열 수 있으며 상세의 휴지통은 스와이프 없는 대체 경로다.

삭제 버튼은 동일한 확인 팝업을 연다. 고정비 이름과 `현재와 이후의 미완료 예정 청구 취소 · 완료 기록 유지`를 안내한다. 취소를 초기 초점으로 두고 모달 초점 제한, Escape로 닫기와 진입 버튼으로 초점 복원을 제공한다. 삭제 중에는 동작을 잠그고, 실패는 팝업 안에 안내하며 재시도를 허용한다. 배경 화면의 삭제나 이동은 성공 응답 후에 수행한다.

- 따뜻한 중립 배경 `#f6f7f4`, 흰 콘텐츠 패널, 짙은 본문 `#17211b`, 녹색 주요 행동 `#225b3e`를 기본으로 한다. 오류·지연은 붉은 계열과 텍스트를 함께 사용한다.
- 본문은 16px 전후, 보조 문구는 12~14px, 제목과 주요 금액은 크기·굵기로 위계를 만든다. 금액은 천 단위 구분과 원 단위를 표시하고 숫자 폭을 일정하게 한다.
- 여백은 4px 배수로 정리하고 카드·버튼·입력의 모서리는 8~16px 범위로 통일한다. 강한 그림자나 장식보다 얇은 경계와 여백을 우선한다.
- 주요 버튼과 입력은 최소 44px 높이, 대표 행동은 48px을 권장한다. 한 화면에는 주요 행동을 분명하게 하나 배치한다.
- 긴 이름과 큰 금액은 줄바꿈을 허용한다. 모바일은 한 열, 넓은 화면은 정보 관계에 따라 재배치한다. 입력 폼은 최대 640px 정도로 읽기 편한 폭을 유지한다.
- 하단 내비게이션이 내용과 버튼을 가리지 않도록 안전 영역과 여백을 확보한다. 페이지 전환·목록 선택·키보드 초점이 눈에 보여야 한다.

## 입력과 피드백

- 모든 입력에 항상 보이는 라벨을 붙인다. placeholder는 예시로만 사용한다. 필수 항목을 안내하고 미정인 선택 항목을 임의로 확정하지 않는다.
- 금액과 반복 결제일은 숫자 입력, 첫 결제일은 날짜 입력, 반복주기·결제자·결제수단은 선택 입력을 사용한다. 혼자 관리에서는 결제자 선택을 숨긴다.
- 반복 결제일의 작은 보조 문구: `첫 결제일과 별도로, 이후 회차에 적용할 날짜입니다.`
- 저장을 시도했을 때 오류 항목에 빨간 테두리와 바로 아래 수정 방법을 표시한다. 첫 오류 입력으로 이동·초점을 주고 `aria-invalid`, `aria-describedby`로 안내를 연결한다. 네이티브 오류 팝업과 중복 표시하지 않는다.
- 사용자가 입력을 수정하면 해당 오류를 해제하고 다음 저장에서 다시 확인한다. 서버 오류는 입력값을 유지하면서 재시도 가능한 문구로 보여준다.
- 저장 중 버튼을 비활성화하고 `저장 중…`으로 표시한다. 완료 결과는 상세 화면이나 상태 메시지에서 확인한다. 동작 줄이기 설정에서는 부드러운 스크롤·장식 애니메이션을 줄인다.

## 모든 화면의 상태와 확인 기준

로딩, 정상, 데이터 없음, 요청 실패와 재시도, 미정 값, 저장 중, 저장 성공을 설계한다. 빈 화면에서는 무엇을 할 수 있는지 짧게 안내하고 추가 행동을 제공한다. 상태는 색상과 문구로 함께 구분한다.

360px와 1280px 폭, 200% 확대, 키보드 이동, 초점 표시와 입력 오류 이동을 확인한다. 모바일에서 가로 스크롤과 잘린 버튼이 없어야 한다. 주요 검증은 Windows Chrome·Edge에서 진행하고 실제 iPhone Safari 교차 확인 여부는 결과에 명시한다.

### 고정비 카테고리 입력

금액 아래에 필수 카테고리 선택 입력을 배치한다. 초기 선택지는 `선택해 주세요`이며, 미선택 시 빨간 테두리·하단 안내와 첫 오류 입력으로의 스크롤·포커스 이동을 제공한다. 조회 화면의 기존 미지정 항목은 `-`로 표시하고 주거·공과금·통신·구독·보험·교육·교통·육아·기타와 사용자가 등록한 지출 카테고리를 보여준다. 목록 마지막의 `+ 카테고리 추가`를 선택하면 해당 입력 아래에 이름·취소·추가를 표시한다. 오류는 이름 입력 테두리와 바로 아래 안내로 표시하고 이름 입력에 포커스를 둔다. 추가 후 새 카테고리를 선택하고 선택 입력으로 포커스를 돌려준다. 이름을 추가하는 동안에는 고정비 저장을 보류한다. 고정비 목록에서는 지출명 위에 작은 중립색 카테고리 태그를 표시하고, 미지정은 `-`로 표시한다. 금액은 지출명과 같은 높이에서 강조한다. 상세 화면에서는 카테고리를 조회하고 `정보 수정`에서 변경한다.
