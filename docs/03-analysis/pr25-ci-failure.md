# PR #25 CI 실패 원인과 수정

2026-10-15, 실패 실행: https://github.com/hkcho11/handal-sallim/actions/runs/38703577404

## 원인

- 웹: 등록 고정비 표시와 테스트는 일정 미정의 null, 반복 결제일과 선택 결제 정보를 사용하는데 커밋된 `FixedExpense` 타입은 이전 필수 일정 계약이었다. 타입 검사에서 TS2322·TS2339·TS2353이 발생했다.
- API: 대시보드 조회·테스트는 거래 테이블, 중분류, 일정 미정과 반복 결제일을 사용하는데 원격에는 V1 마이그레이션만 있었다. 대시보드 테스트 4개가 SQL 오류로 실패했다.
- 기존 검증은 미커밋 변경이 포함된 로컬 작업 공간을 대상으로 실행되어 PR의 실제 파일 구성을 검증하지 못했다.

## 수정과 검증

- 기존 API 응답과 호환되도록 웹 타입·응답 검증에 일정 미정과 선택 결제 정보를 포함하고 정상·비정상 응답 회귀 테스트를 추가했다.
- 이미 로컬에서 사용하던 V2~V5 Flyway 마이그레이션을 PR에 포함했다. 배포·실제 DB 초기화나 데이터 삭제는 수행하지 않았다.
- HEAD를 임시 디렉터리로 내보내 수정 파일만 적용하고 의존성을 lockfile대로 설치했다. 이 사본에서 API Spotless·JUnit 11개·빌드, 웹 타입 검사·린트·포맷·Vitest 37개·빌드·Playwright 11개를 확인했다.
- 등록 기능 등 기존 미커밋 작업은 덮어쓰지 않고, 검증한 파일 내용만 커밋했다. 앞으로 PR 검증은 제출할 파일 구성과 일치하는 사본 또는 CI 결과로 확인한다.

## 이메일

실패 메일은 GitHub Actions의 개인 알림 설정에서 발송한다. 워크플로를 끄거나 실패를 무시하는 방식으로 감추지 않는다. 계정 로그인 후 https://github.com/settings/notifications 의 System → Actions에서 이메일 알림을 해제할 수 있다. 현재 연결 브라우저는 로그인되어 있지 않아 설정을 변경하지 않았다.
